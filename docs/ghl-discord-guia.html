Configuración en 5 minutos

Notificaciones de agendas GHL → Discord

GHL envía solamente el ID del contacto y el canal de Discord. El servidor busca automáticamente la cita, el closer y las respuestas de la encuesta.

1 · GHLEnvía el ID
2 · ServidorBusca toda la información
3 · DiscordRecibe una sola notificación
1

Crear el workflow en GHL

  • Ir a Automatizaciones → Workflows.
  • Usar el trigger Customer Booked Appointment.
  • Filtrar los calendarios o estados que deban generar la notificación.
  • Agregar una espera de 30 a 60 segundos después del trigger.
  • Agregar la acción Custom Webhook.
¿Por qué hay que esperar? Así GHL termina de guardar la cita y la encuesta antes de que el servidor las consulte.
2

Configurar el Custom Webhook

Método
POST
URL
https://central.matirandazzook.com/api/ghl/appointment-booked
Endpoint 
https://central.matirandazzook.com/api/ghl/appointment-booked
3

Agregar dos headers

Header 1
Content-Type → application/json
Header 2
X-Webhook-Secret → usar el secreto temporal indicado debajo
Valor de X-Webhook-Secret 
822310e49855db0b52184e01ae7b3b0c3a6cbb3a0a6a6a271fe995537e8c3355
No pegues el token de la API de GHL acá. En este header va solamente el secreto temporal de arriba. Debe coincidir exactamente con GHL_APPOINTMENT_WEBHOOK_SECRET en Render.
4

Pegar este body JSON

En GHL, elegí Contact ID desde el selector de valores dinámicos. Después reemplazá el webhook de ejemplo por el del canal de Discord.

Body JSON 
{
  "contact_id": "{{contact.id}}",
  "discord_webhook_url": "https://discord.com/api/webhooks/ID/TOKEN"
}
Eso es todo lo que envía GHL. No hace falta mandar fecha, closer, calendario, nombre, email, respuestas ni ID de la cita.
5

Guardar, publicar y probar

  • Guardar la acción Custom Webhook.
  • Publicar el workflow.
  • Crear una cita de prueba con un contacto que haya completado una de las cuatro encuestas.
  • Esperar aproximadamente un minuto y revisar el canal de Discord.
✓

Qué debería pasar

En Discord

Llega un único mensaje con lead, teléfono, email, fecha, closer, calendario, enlace al contacto y respuestas de la encuesta.

No se envía

No aparece el enlace de la reunión. Tampoco se muestran IP, UTMs, campañas, IDs publicitarios, score ni datos internos.

?

Si no llega la notificación

Error 400
Falta el contact_id o el webhook de Discord no es válido.
Error 401
El valor de X-Webhook-Secret no coincide con Render.
Error 404
No se encontró una cita reciente de ese contacto en las agendas configuradas.
Error 503
Falta alguna credencial o variable necesaria en el servidor.
Importante después de la prueba Este documento contiene el secreto temporal para facilitar el test del desarrollador. Cuando termine la validación, generá otro valor para GHL_APPOINTMENT_WEBHOOK_SECRET, actualizalo en Render y en el workflow de GHL, y eliminá el anterior.
